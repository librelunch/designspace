# designspace

A Python library for declaratively defining algorithm design spaces using a
chainable, polars-like expression API. Pre-implementation scaffold.

- `API_v3.md` — the normative specification
- `IMPLEMENTATION_PLAN.md` — milestone plan (M0–M13) with conformance gates
- `CLAUDE.md` — working rules for the implementing agent
- `PROGRESS.md` / `DECISIONS.md` — execution log and ambiguity ledger

Status: scaffold only; implementation begins at M0.
